# Sample / solution

## Why this approach works
The paste decision turns on status, not just visible content. The three questions (who is in this, who is it for, what is its release status) catch what a quick name-scan misses: C3 contains no personal details and is still a Never because it was never cleared for release, and C7 is a Never because exploited-weakness detail is sensitive even though no person is named. The two caution cases, C4 and C8, teach the second habit: a label like "aggregated" or "synthetic" is a claim, and someone must confirm it before the content is safe to paste. "No identifiers visible, so OK" is the failure mode this exercise exists to kill, because the paste takes a second and the incident review takes weeks. The approved-tool question (Copilot under a government agreement) settles only which account you may use; the data-class test still decides what may go into the prompt.

## A complete solution
Full placement, and the chat line for remote participants: `C1-OK, C2-Never, C3-Never, C4-Mask, C5-Never, C6-OK, C7-Never, C8-Mask`. That is: OK bucket, C1 (public park-hours webpage text, public content, still verify the output) and C6 (a published open data dictionary). Never bucket, C2 (a resident's name, phone number, and service address: direct identifiers, exactly what the Privacy Act covers), C3 (internal draft policy marked deliberative, not for release), C5 (an employee's performance feedback note: personal HR information), and C7 (a security incident timeline with system names and an exploited weakness: sensitive security detail). Mask first bucket, C4 (aggregated statistics: only safe once someone confirms the small-cell suppression rules were actually applied) and C8 (synthetic citizen records: only safe once someone confirms they are truly synthetic and carry no echo of real cases).

Take C3, the classic split. The wrong instinct is "no names in it, so it is fine to paste." The defense sounds like this: "Release status decides, not content. This draft is marked deliberative, not for release, which means the agency has not yet decided what in it may become public. Pasting it into an AI tool is an unreviewed release of pre-decisional material, and the absence of personal details changes nothing about that. If I need the same kind of help, I paste a cleared public policy instead, or I ask the structural question with no draft text at all." The policy question to check first, posted as the board comment: for C4, "who confirmed the small-cell suppression rules were applied to these statistics?" If you finish early, the masked rewrite of C2 is "a resident at a service address in Ward 3," which keeps the analytical value and drops every identifier.
