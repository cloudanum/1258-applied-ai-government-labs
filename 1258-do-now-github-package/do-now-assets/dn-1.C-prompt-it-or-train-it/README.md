# Do Now 1.C: Prompt It or Train It? 🎯

**Time:** 5 minutes
**Format:** No sandbox or tooling required — this activity is done mentally and captured directly on the Mural board (or in Zoom chat if you are remote).
**Mural:** https://app.mural.co/t/day10626/m/day10626/1790240785053/4d2306d3f1c8e18b1a64d00a9ab6ef15a7eaa29c

## Goal
By the end of this five-minute warm-up you will have sorted six task stickies (T1–T6) into **Prompt**, **Train**, or **Hybrid** and written one sentence defending your hardest call. The artifact is a sorted board plus a written reason — and the instinct underneath is the build-vs-ask decision that drives cost, schedule, and staffing on every government AI project: prompting works when the context fits in the request and the task is occasional, while training earns its keep only when scale, labeled data, and repeatability justify a pipeline. You are also learning to spot the honest middle — tasks that start as prompts and graduate to training only when the volume proves it.

## Why it matters
Choosing prompt vs. train is a procurement decision in disguise: one path is an afternoon and an API call, the other is labeled data, a pipeline, an owner, and a retraining cadence. Sorting becomes defensible when learners must place, mark, or choose and then explain one decision.

**Assets:** Task stickies T1–T6 (see `board-items.tsv`).

## Run steps 🪜
1. Open the Mural board linked above and read all six task stickies T1–T6, noting the scale signal in each — one uploaded council report in a meeting (T3) is a different universe from 2 million service requests a night (T2).
2. Drag each sticky into **Prompt**, **Train**, or **Hybrid**. Working remotely? Post your six placements in Zoom chat instead, e.g. `T1-Prompt, T2-Train...`.
3. For each **Train** placement, sanity-check the three justifiers — sustained volume, a source of labels, and a repeatable definition of correct; T4's weekly confirmed-fraud labels pass all three.
4. For each **Prompt** placement, confirm the needed context actually fits in the request — T3's single report does; T6's city-wide photo fleet does not.
5. Add a Mural comment (or chat reply) on your least-certain sticky with your one-sentence reason.
6. Find one sticky where you disagree with another learner and mark it — listen to their argument before the key is revealed.
7. Initial or color-tag your stickies as your final answer before the instructor walks the key.

## Key takeaway 💡
Prompt when the context fits in the request and the task is occasional; train only when scale, labels, and repeatability justify a pipeline — and treat "it sounds important" as a reason to check the numbers, not a reason to train.

## Common mistake to name ⚠️
Choosing **Train** because a task sounds important — importance is not scale; choose Train only when sustained volume, a label source, and repeatability all line up, as they do for T2 and T4.
