# Sample / solution

## Why this approach works
The sort works because prompt vs. train is a resource question, not a prestige question. Prompting wins when the context fits in the request and the task is occasional: an afternoon and an API call, with no pipeline, no owner, and no retraining cadence. Training earns its keep only when three justifiers line up at once, sustained volume, a source of labels, and a repeatable definition of correct, because you are buying labeled data, a pipeline, an owner, and a maintenance schedule. The weaker instinct, choosing Train because a task sounds important, is exactly the failure mode this exercise names: importance is not scale, and an unneeded training pipeline is a procurement and staffing commitment with nothing to show for it. The honest middle is real: most good Train placements start life as a prompt pilot and graduate only when the volume proves it.

## A complete solution
T6 is the stickiest call. A full defense sounds like this: "I place T6 in Train. The modern instinct is to prompt a general vision model with 'is this stop sign damaged?', and that is exactly how I would pilot it. But the deciding factors are fleet-wide volume and consistency: thousands of photos a day need the same definition of 'damaged' applied the same way every time, with an error rate the roads division can audit. A prompted general model drifts on borderline cases and gives you no stable answer key to test against; a trained vision classifier gives you a repeatable, auditable decision." That defense earns the point because it names the mechanism (consistent high-volume classification), the failure mode of the wrong call (inconsistent, untestable judgments), and the honest path (prompt the pilot, train when the volume proves it).

The rest of the board sorts cleanly once you read the scale signal in each sticky: T1, T3, T5 to Prompt (existing context in the request, one uploaded council report, three formats of a single notice); T2, T4, T6 to Train (nightly volume over 2 million requests, weekly confirmed-fraud labels as a live label source, fleet-wide photo classification). Posted remotely: `T1-Prompt, T2-Train, T3-Prompt, T4-Train, T5-Prompt, T6-Train`. If you cannot name a Train sticky's label source, owner, and retraining cadence, argue it back down to Prompt; T2 and T4 survive that test, which is what makes them real Train placements.
