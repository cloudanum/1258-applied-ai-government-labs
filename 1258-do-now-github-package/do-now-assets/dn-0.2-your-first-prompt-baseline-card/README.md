# Do Now 0.2: Your First Prompt (Baseline Card) 🎯

**Time:** 5 minutes
**Format:** No sandbox or tooling required, this activity is done mentally and captured in your private notes; you will share only one insight, never the prompt itself, in Zoom chat or on the Mural board.
**Mural:** https://app.mural.co/t/day10626/m/day10626/1790240781052/ff7828405c7e56531c023551b2955e9f1b9c2ed8

## Goal
By the end of this five-minute warm-up you will have written down one real prompt exactly the way you would naturally write it today, your honest "P0" baseline, plus one line naming what you assumed the model already knew. The artifact is a private baseline card that stays with you for the whole course: every prompting technique you learn later gets measured against this starting point. The skill underneath is self-awareness as a prompt writer, most people have never seen their own unedited prompt written down, and that unseen baseline is exactly where habits like missing context, missing format, and assumed knowledge hide. Keeping it private is deliberate: honesty about a real work task requires a channel that never exposes sensitive content.

## Why it matters
You cannot improve a prompt you have never honestly captured. The private channel is part of the lesson: government staff need a way to examine their own AI habits without pasting real work content into a shared board, the capture rule itself models the data-handling caution this course teaches.

**Assets:** Private notes/Prompt Card.

**🌐 MS Co-pilot Specific Info:** Write your baseline prompt P0 by actually running it once in your agency's Copilot (web or Edge sidebar) before class, the honest “before” sample is the whole point. Keep the prompt and output private.

## Run steps 🪜
1. Pick one real task from your current work that you might plausibly hand to an AI assistant, drafting, summarizing, reformatting, anything genuine.
2. In your private notes (paper or a local file, not the Mural board, not Zoom chat), write the prompt exactly as you would type it today. Do not polish it.
3. Label it `P0` and add the date, this is your baseline card.
4. Underneath, finish one sentence: `Assumed the model knew ___.` (the context? the tone? the required length? who the reader is?)
5. Check the card for anything sensitive: if the task involves personal or internal data, describe the task generically rather than pasting real content.
6. When the instructor asks, share only one insight in Zoom chat or as a Mural sticky, for example, "I assumed the model knew my reader", never the prompt itself.

## Key takeaway 💡
Your unedited "P0" prompt is the most valuable prompt you own, because every improvement you learn this course is measured against it, capture it honestly and privately before anyone teaches you to write a better one.

## Common mistake to name ⚠️
Rewriting or "improving" the baseline while you capture it, a polished P0 is worthless, because the value is the honest sample of how you actually prompt today, warts and all.

## If finished early ⏩
Add one line to the card: what evidence would change your mind about this task being safe for AI? Then list the two or three details a colleague would need to run the task that your prompt leaves out.

## ⭐ Bonus (optional)
Write a second baseline card for a task you would *never* give to an AI tool, and in one sentence name the specific property, sensitivity, stakes, accountability, that puts it off-limits. Comparing the two cards is your first personal AI-use policy.
