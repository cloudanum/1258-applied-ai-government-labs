# Sample / solution

## Why this approach works
The value of the card is its honesty, not its quality. An unedited P0 is the only honest measurement of how you actually prompt, and every technique in the course gets measured against it; a polished P0 measures nothing because it describes a prompter who does not exist. The verb mapping works because Bloom's levels classify the task, not the model: the same assistant that flawlessly extracts a date can invent a legal precedent minutes later, and what changed was the cognitive level of the request. Naming a home level turns that insight into a personal risk profile, because L1–L2 work has answer keys and is checkable while L5–L6 verdicts and inventions are not. The private-first, then sensitivity-check design rehearses the same paste/no-paste test you should run before anything leaves your desk.

## A complete solution
A complete baseline card, written in private notes and dated:

```
P0 (2026-09-26): "Summarize the attached for the director, keep it short, flag anything urgent."
Sensitivity check: touches internal correspondence, so the raw prompt stays private; the shared version is the one-line generic description "summarize an internal briefing note for a director."
Frequent use cases: (1) summarize long email threads and briefing notes, (2) extract dates, deadlines, and reference numbers from correspondence, (3) explain acronyms and classify incoming requests for routing.
Top 4 verbs: summarize (L2), extract (L1), explain (L2), classify (L3).
My home level: L2
```

The mapping is the teaching moment: three of the four verbs land at L1–L2, the retrieval and paraphrase zone where every output can be checked against the source text, and only `classify` reaches L3, where the answer is constrained by a rule but no longer quoted from the document. The honest instinct to resist is listing impressive verbs like `recommend` (L5) because they sound senior; the card is only useful if the verbs are the ones you really use. When the instructor asks, the Zoom chat share line is:

`Home level L2 | P0: "summarize an internal briefing note for a director"`

Note that the shared line carries the sanitized description, not the raw prompt: the sensitivity check is what makes the honest private sample safe to talk about in the room.
