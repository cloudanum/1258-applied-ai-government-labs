# Sample / solution

## Why this approach works
The card's value is its honesty, not its quality: a polished P0 measures a prompter who does not exist. Mapping your real verbs to Bloom levels turns that sample into a personal risk profile, because L1–L2 work has answer keys and L5–L6 work does not.

## A complete solution
A complete baseline card, written in private notes and dated:

```
P0 (2026-09-26): "Summarize the attached for the director, keep it short, flag anything urgent."
Sensitivity check: touches internal correspondence, so the raw prompt stays private; the shared version is the one-line generic description "summarize an internal briefing note for a director."
Frequent use cases: (1) summarize long email threads and briefing notes, (2) extract dates, deadlines, and reference numbers from correspondence, (3) explain acronyms and classify incoming requests for routing.
Top 4 verbs: summarize (L2), extract (L1), explain (L2), classify (L3).
My home level: L2
```

Three of the four verbs land at L1–L2, the retrieval and paraphrase zone where every output can be checked against the source text; only `classify` reaches L3. The verbs listed are the ones actually used, not impressive-sounding ones like `recommend` (L5). When the instructor asks, the Zoom chat share line is:

`Home level L2 | P0: "summarize an internal briefing note for a director"`

The shared line carries the sanitized description, not the raw prompt: the sensitivity check is what makes the honest private sample safe to share.
