# Do Now 1.A: Classic ML or GenAI? 🎯

**Time:** 5 minutes
**Format:** No sandbox or tooling required, this activity is done mentally and captured directly on the Mural board (or in Zoom chat if you are remote).
**Mural:** https://app.mural.co/t/day10626/m/day10626/1790240783064/24453072664cc74ad063b2f25e6e9ce40f6c59f0

## Goal
By the end of this five-minute warm-up you will have sorted eight real government use-case stickies (U1–U8) into three buckets, **Classic ML**, **GenAI**, or **Neither/Depends**, and defended at least one placement out loud. The point is not just to sort correctly: it is to build the instinct that prediction, classification, and optimization problems are usually classic machine-learning territory, while drafting, summarizing, and rewording language is generative-AI territory, and that some problems sit honestly in between. You will leave the board with one flagged "uncertain" item and a written reason for your hardest call.

## Why it matters
Choosing classic ML vs. GenAI is the first architecture decision on any government AI project, and it drives cost, risk, data needs, and oversight obligations. Sorting becomes defensible when learners must place, mark, or choose and then explain one decision to the group.

**Assets:** Use-case stickies U1–U8 (see `board-items.tsv`).

**🧩 Pattern watch:** Design pattern, **Right tool for the task**: route prediction and scoring to classic ML, language work to GenAI. Anti-pattern, **GenAI hammer**: when every problem looks like a prompt, forecasting ends up done by a chatbot.

## Run steps 🪜
1. Open the Mural board linked above (or follow along in Zoom chat if the instructor is running it verbally).
2. Read all eight use-case stickies U1–U8 slowly, note the verb in each one (predict, draft, detect, cluster, generate...).
3. Drag each sticky into the **Classic ML**, **GenAI**, or **Neither/Depends** column. Working remotely? Type your eight placements in Zoom chat instead, e.g. `U1-ML, U2-GenAI...`.
4. Pick the one sticky you were least sure about and add a Mural comment (or chat message) explaining your reasoning in one sentence.
5. Compare your board with a neighbor or the room: find one sticky where you disagreed and listen to the other argument.
6. Mark your final answer by initialing or color-tagging your stickies before the instructor reveals the key.

## Key takeaway 💡
If the core job is predicting a number or label from historical data, think classic ML; if it is producing or transforming language, think GenAI, and when you cannot tell, that uncertainty itself is worth flagging, because it usually means the use case needs sharper definition before any tool is chosen.
