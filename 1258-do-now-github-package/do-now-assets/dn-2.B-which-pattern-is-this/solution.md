# Sample / solution

## Why this approach works
Sorting by the underlying job, not by surface keywords, is what makes each placement defensible: the signal verb on each sticky fixes the pattern. The pattern then fixes the data you need, the evaluation plan, and the most likely failure mode before any vendor enters the conversation.

## A complete solution
Full placement: E1 dataset discovery/search, E2 classification, E3 clustering, E4 regression/forecasting, E5 grounded QA (RAG-like), E6 anomaly detection, E7 information extraction/NER, E8 GenAI transformation. Posted remotely, the chat line is `E1-discovery, E2-classification, E3-clustering, E4-regression, E5-grounded-QA, E6-anomaly, E7-extraction, E8-transformation`.

Take E5, "A chatbot answers only from the current policy PDF," the one most people hesitate on. The defense: "The chatbot interface is surface detail. The job is answering, and the answer is constrained to one fixed, approved document. That is grounded QA, and the test is whether every claim traces back to the PDF. E8 is the mirror image: it takes known text and produces new language, so nothing needs grounding and the failure mode is drifting from the source meaning. Same model family, different pattern, different evaluation plan." If a neighbor placed both under GenAI, ask how they would test each one, and the difference surfaces on its own.
