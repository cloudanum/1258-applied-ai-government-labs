# Do Now 2.B: Which Pattern Is This? 🎯

**Time:** 5 minutes
**Format:** No sandbox or tooling required, this activity is done mentally and captured directly on the Mural board (or in Zoom chat if you are remote).
**Mural:** https://app.mural.co/t/day10626/m/day10626/1790240788055/1f6f0adf26c5e93e2cc2498c4a523fdf13e070c5

## Goal
By the end of this five-minute warm-up you will have matched eight real-world example stickies (E1–E8) to the data/AI pattern each one represents, dataset discovery, classification, clustering, regression/forecasting, grounded QA (RAG-like), anomaly detection, information extraction (NER), or GenAI transformation, and flagged the one example you found hardest to place. The artifact is a fully sorted board plus one written defense of your trickiest call. The deeper point is pattern recognition: nearly every government AI system you will ever scope is one of a small set of repeatable patterns, and naming the pattern early tells you what data you need, how you will test it, and how it will fail. You will leave with the instinct to ask "which pattern is this?" before asking "which tool should we buy?".

## Why it matters
Naming the underlying pattern is how experienced teams scope AI work quickly and defensibly, it drives data requirements, evaluation method, and risk profile before a single dollar is spent. Matching becomes defensible when learners must place, mark, or choose and then explain one decision to the group.

**Assets:** Example stickies E1–E8 (see `board-items.tsv`).

## Run steps 🪜
1. Open the Mural board linked above (or follow along in Zoom chat if the instructor is running it verbally).
2. Read all eight example stickies E1–E8 slowly, underline the verb in each one mentally: *find* datasets (E1), *label* documents (E2), *group* comments (E3), *predict* breaks (E4), *answer* from a PDF (E5), *flag* unusual transactions (E6), *extract* names and dates (E7), *rewrite* a notice (E8).
3. Drag each sticky onto its matching pattern name on the board: dataset discovery/search, classification, clustering, regression/forecasting, grounded QA (RAG-like), anomaly detection, information extraction/NER, or GenAI transformation. Working remotely? Post all eight placements in Zoom chat as `E# pattern-name`, e.g. `E1-discovery, E2-classification...`.
4. Pick the sticky you were least sure about, E5 and E8 both involve language models but are different patterns, and add a Mural comment (or chat message) explaining your reasoning in one sentence.
5. Compare your board with a neighbor or the room: find one sticky where you disagreed and listen to the other argument.
6. Initial or color-tag your stickies to lock in your final answer before the instructor reveals the key, note any placement you change, and why.

## Key takeaway 💡
Once you can name the pattern, classify, cluster, forecast, extract, ground, generate, you already know the data the system needs, how to evaluate it, and its most likely failure mode, before any vendor or tool enters the conversation.

## Study further 📚
- [Getting Started with scikit-learn, scikit-learn](https://scikit-learn.org/stable/getting_started.html), official introduction to the classic patterns: classification, regression, and clustering.
- [Retrieval-augmented generation (RAG) use cases, Google Cloud](https://cloud.google.com/use-cases/retrieval-augmented-generation), how grounded QA over documents like the E5 policy PDF actually works.
- [Token Classification, Hugging Face NLP Course](https://huggingface.co/learn/nlp-course/en/chapter7/2), the mechanics of named-entity recognition, the E7 information-extraction pattern.

## Common mistake to name ⚠️
Matching by surface keyword instead of underlying job, seeing "chatbot" or "rewrites" and shouting GenAI, when E5 is grounded QA and E8 is transformation. Require one placement to be defended out loud before the answer key is shown.
