# Sample / solution

## Why this approach works
Mapping all six roles before writing anything works because AI pilots stall on missing people more often than on missing technology, and the map is cheapest to draw while the pilot is still on paper. Each role answers a different launch-blocking question: sponsor, is this allowed to exist and be funded; data owner, may we use this text; security, where does the data go; legal/privacy, what must be masked or consented; operations, who runs it daily; end user, will anyone actually use it. Marking the one role you do not currently have, and writing the first specific ask, is what turns "we should really talk to legal" into a calendar item. The weaker instinct, "the IT department will handle it," fails because no single role owns data permission, privacy sign-off, and daily adoption at the same time.

## A complete solution
For the permit-intake use case from Do Now 9.B, all six stickies get placed: sponsor (permits division director), data owner (permits records or system owner), security (the agency security office, to confirm the tool boundary), legal/privacy (privacy officer), ops (intake team supervisor), and end user (the permit intake staff themselves). The one circled as missing, the common case for government teams, is privacy/legal.

The visible Mural comment, which is also the remote chat fallback in the capture format: `Missing role: privacy/legal | First ask: Can resident complaint or inquiry text be used in a pilot, and what must be masked before it goes near the tool?`

The defense a learner should give aloud: "I marked privacy/legal missing because this use case reads resident text, which can contain names, addresses, and case details we did not collect for this purpose. My first ask is specific: whether that text can be used in a pilot at all, and what must be masked. I did not mark security missing because our security office already has a standing intake process, but there is no standing path for privacy review of secondary use of resident text, so that is the gap that would stall us." If a neighbor marked a different role, for example data owner because permit records live in a legacy system nobody owns cleanly, that is a valid disagreement, and comparing the two maps is the point of the exercise.
