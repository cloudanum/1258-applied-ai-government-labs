# Sample / solution

## Why this approach works
AI pilots stall on missing people more often than on missing technology, and the map is cheapest to draw while the pilot is still on paper. Naming the one role you lack, and your first specific ask, turns "we should really talk to legal" into a calendar item.

## A complete solution
For the permit-intake use case from Do Now 9.B, all six stickies get placed: sponsor (permits division director), data owner (permits records or system owner), security (the agency security office), legal/privacy (privacy officer), ops (intake team supervisor), and end user (the permit intake staff themselves). The one circled as missing is privacy/legal.

The visible Mural comment, which is also the remote chat fallback in the capture format: `Missing role: privacy/legal | First ask: Can resident complaint or inquiry text be used in a pilot, and what must be masked before it goes near the tool?`

The defense a learner should give aloud: "I marked privacy/legal missing because this use case reads resident text, which can contain names, addresses, and case details we did not collect for this purpose. My first ask is specific: whether that text can be used in a pilot at all, and what must be masked. I did not mark security missing because our security office already has a standing intake process, but there is no standing path for privacy review, so that is the gap that would stall us." A neighbor who marked a different role, for example data owner because permit records live in a legacy system nobody owns cleanly, has a valid disagreement; comparing the two maps is the point of the exercise.
