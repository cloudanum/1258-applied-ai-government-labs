# 1258 Do Now standalone package

Open `1258-DoNow-Master-Guide-Standalone.html` first. It links each Do Now to its asset pack under `do-now-assets/`.

Contents:
- `1258-DoNow-Master-Guide-Standalone.html` — searchable/linked master guide with activity↔solution links, relative asset-pack links, and the same enriched content as the asset folders (comprehensive goals, detailed run steps, key takeaways, Study Further links, bonus tasks). No sandbox required — everything runs mentally on Mural or in Zoom chat.
- `1258-DoNow-Master-Guide-Standalone.pdf` — 92-page print copy regenerated from the enriched HTML.
- `do-now-assets/` — 41 numbered asset folders with enriched READMEs (comprehensive goal, detailed run steps for Mural/Zoom-chat delivery, key takeaway, validated Study Further links, optional bonus tasks), links, board-item TSVs, solutions, and generated sample images. No sandbox or tooling required — all activities run mentally on Mural or in Zoom chat.
- `accuracy-validation.json` / `url-validation.json` — validation reports for activity coverage and URLs (including the Study Further links).
- `enrich_guide.py` — regenerates the master guide HTML from the asset-folder READMEs; reprint the PDF with headless Chrome after running it.

Use in class: share one Mural link at activity start. Use `do-now-assets/manifest.tsv` as the index.
